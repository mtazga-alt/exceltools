أدوات الإكسيل — تطبيق PWA يعمل بدون اتصال

الرفع على GitHub Pages:
1) أنشئ مستودع جديد (مثلاً adawat-excel) وارفع كل الملفات دي في جذره.
2) Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3) افتح الرابط https://USERNAME.github.io/adawat-excel/ من موبايلك مرة واحدة وانت متصل.
4) من قائمة Chrome اختر "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية" (في آيفون: Safari > مشاركة > إضافة إلى الشاشة الرئيسية).
بعدها يفتح كتطبيق ويشتغل أوفلاين تماماً.

لتحديث التطبيق لاحقاً: غيّر رقم CACHE في sw.js (v1 -> v2) مع رفع الملفات الجديدة.
